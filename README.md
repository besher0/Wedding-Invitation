# ليلتنا — Wedding Invitation Platform

واجهة عربية متجاوبة لتصميم دعوات زفاف إلكترونية مع قوالب متحركة ومعاينة مباشرة.

## التشغيل

يتطلب Node.js 20+.

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يعرضه Vite. لفحص نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## الميزات المنفّذة في نموذج الواجهة

- الرئيسية ومعرض ثلاثة قوالب (وردي / ذهبي / ليلي).
- محرّر أسماء العروسين والمقدمة، العائلات، التاريخ، الوقت، القاعة والعنوان والرابط.
- معاينة متحركة لفتح الظرف وتفاصيل الدعوة.
- اختيار أغنية محلية تبدأ بعد تفاعل المستخدم.
- حفظ المسودات في localStorage داخل المتصفح وتعديلها وحذفها.

## حدود هذه المرحلة

**هذا نموذج Frontend فقط**: لا يوجد تسجيل دخول، API، قاعدة بيانات، رفع أغاني للسيرفر، نشر رابط دعوة عام، دفع، ولا مزامنة بين الأجهزة. زر المشاركة تجريبي ولا يمثّل نشر الدعوة. يجب عدم استخدامه كمنتج SaaS مكتمل.

## خارطة الطريق

1. NestJS API مع Prisma وPostgreSQL، جلسات المستخدمين وصلاحياتهم.
2. تخزين القوالب بإصدارات ومحتوى دعوات JSONB مع تحقق المدخلات.
3. حفظ المسودات على السيرفر، النشر برابط فريد ومعاينة OpenGraph.
4. رفع صور وأغاني مع صلاحيات وقيود ملف وحقوق الاستخدام.
5. لوحة أدمن، إحصائيات، مشاركة QR والدفع لاحقاً.
